# AGENTS.md

## Rules

- Keep only generic targets in `desired/`.
- Keep full dumps in `mapringg.android.snapshots` and save them after every snapshot.
- Keep personal targets in `mapringg.android.private` and save them after editing.
- Run `secret restore` if a private folder is missing.
- Put targets exclusive to the Settings app in `desired/ui.txt`.
